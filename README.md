# Vite + Vue 3 Project

This project is built using [Vite](https://vitejs.dev/) and [Vue 3](https://vuejs.org/). Vite offers fast bundling and a modern development experience, while Vue 3 brings the Composition API and other improvements.

## 🚀 Project Setup

### 1. Clone the Repository

```bash
(https://github.com/imPrinceSingh/product-management.git)
cd Product Management

```
Install Dependencies
  npm install
  npm run dev
